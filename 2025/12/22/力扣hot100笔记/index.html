124. 二叉树中的最大路径和hard

在代码中，dfs 函数的核心作用是计算「单边分支最大和」，而 root.val + leftMax + rightMax 则是计算以当前节点为「顶点」的「横向路径最大和」。

  • 单边分支：从当前节点出发，只能向「左子树」或「右子树」中的一个方向延伸的路径（因为路径不能分叉，否则无法向上拼接父节点）。例如：root -> 左子树的某条路径 或 root -> 右子树的某条路径。
  • 横向路径：以当前节点为「最高点/起始根节点」，同时向「左子树」和「右子树」延伸的路径（即 左子树路径 -> root -> 右子树路径）。这条路径无法再向上拼接父节点（因为已经同时用了左右两个方向），但可能是全局最大路径。

  •   class Solution {
      public int maxAreaOfIsland(int[][] grid) {
          int m = grid.length,n=grid[0].length,maxArea = 0;
          for(int i=0;i<m;i++){
              for(int j=0;j<n;j++){
                  maxArea = Math.max(maxArea,dfs(i,j,grid));
              }
          }
          return maxArea;
      }
      public int dfs(int i,int j,int[][] grid){
          if(i<0 || j<0 || i>=grid.length || j>=grid[0].length || grid[i][j]!=1) return 0;
          grid[i][j] = 2;
          int area = dfs(i+1,j,grid) + dfs(i-1,j,grid) + dfs(i,j+1,grid) + dfs(i,j-1,grid) + 1;
          return area;
      }
  }

我们要解决的问题是：DFS 遍历这棵树，遍历到节点 node 时，假设 node 是路径的终点，那么有多少个起点，满足起点到终点 node 的路径总和恰好等于 targetSum？

39. 组合总和中等

给你一个 无重复元素 的整数数组 candidates 和一个目标整数 target ，找出 candidates 中可以使数字和为目标数 target 的 所有 不同组合 ，并以列表形式返回。你可以按 任意顺序 返回这些组合。

candidates 中的 同一个 数字可以 无限制重复被选取 。如果至少一个数字的被选数量不同，则两种组合是不同的。

这道题是 完全背包问题 的变种，也是最标准的 回溯算法（Backtracking） 题目之一。

与上一题《括号生成》不同的是：这里做选择时，选了一个数之后，下一层递归还可以继续选这个数（因为可以无限制重复被选取）。

核心思路

  1. **路径记录 (path)**：记录当前选了哪些数。
  2. 结束条件：
    • target == 0：说明凑够了，将当前路径加入结果集。
    • target < 0：说明选多了，这条路走不通，回溯。
  3. 去重与顺序：
    • 为了防止出现 [2, 3] 和 [3, 2] 这种重复组合，我们需要控制遍历的顺序。
    • 关键点：在递归时传入一个 begin 索引。下一层递归从 begin 开始遍历，而不是从 0 开始。
  4. 可重复选取：
    • 递归调用时，传入的索引依然是 i（当前索引），而不是 i + 1。这表示“我可以继续选当前的数”。

剪枝优化

为了提高效率，我们可以先对数组进行 排序。如果在 for 循环中发现 candidates[i] > target，那么后面的数肯定也都比 target 大（因为已经排好序了），直接 break 即可，不需要继续递归。
